## 四、关键设计决策（与基线/研究的对应）

1. **变更协议 = Univer 三层模式**（研究报告 §02）：COMMAND/OPERATION/MUTATION 落在 `core/command.ts` + `data/command-service.ts`；反演工厂（`createUndo` 在 apply 前基于当前状态计算反演 mutation，自反型如 set-cells 新旧互换、互逆型如 insert↔delete 跨 mutation 反演、丢失型如 delete-rows/删表先抢救数据）；`sequenceExecute` 伪事务（失败回滚不入栈）。修掉了 Univer 的两个债：undo 组装样板提炼为统一路径；结构变更（插删行/删表）**全部可撤销**（AG Grid 的反面教训）。
2. **渲染 = 单 canvas + 逻辑层 pass**（研究报告 §04 建议被采纳）：5 个 zIndex 层（背景/网格/内容/覆盖/表头）在一张 canvas 上按序绘制，层内 `clip/clip-end` 指令裁剪（滚动内容不越进表头带）；RenderScheduler rAF 帧合流 + 内容版本号区分「滚动帧（位块搬移）」与「内容帧（脏区重绘）」——**硬红线：任何路径只标脏不直画**。
3. **布局 = Fenwick 树状数组**（正式方案 §2）：行高变化 O(log n) 不重建；逆查用二分下降技巧；百万行 8MB Float64。**列模型用简单前缀**（列数少、变更重建 O(n) 划算——规模不对称的差异化决策）。
4. **公式 = RTree 蓝图的 v1 简化版**（研究报告 §10）：依赖图持久维护（非 Luckysheet/FS 式每次重建）；线性扫描 + 区间包含判断（≤5000 公式量级实测够用）；INDIRECT/OFFSET/INDEX 标记 dynamic 每次重算；**递归下降 Parser**（不踩 Univer 移栈 Lexer 自认过度复杂的坑）；错误是值不是异常（#DIV/0! 传播）；计算不写回存储、结果入缓存（isomorphic，可进 Worker）。
5. **交互 = 显式 FSM + 优先级键位表**：Luckysheet 20 个布尔位状态机的反面教材驱动；键位 priority 分层（10 撤销 / 20 选择 / 30 编辑入口 / 100 导航 / 200 printable）；`printable` 键位实现「直接打字即编辑」（Excel 语义）。
6. **纯前端边界**（产品边界基线）：RemoteAdapter/远程搜索/XLSX 全部是回调契约，引擎里 grep 不到任何 fetch/网络代码。
7. **许可红线执行**：Univer(Apache-2.0)/HyperFormula(GPL) 只借鉴思想，无一行复制；源码注释中所有"借鉴 Univer 思想"处均有标注。

## 五、实现中发现并修复的真 Bug（benchmark/测试驱动）

1. **`splice(clamped, 0, ...ids)` 百万参数爆栈**（100 万行基准暴露）→ 尾插 push 循环 + 中插 concat；
2. **公式引用公式读到原始空值**（集成测试暴露）→ FormulaEngine 内建缓存感知取值源；
3. **Fenwick 逆查边界像素归属错行**（`>` vs `>=`，边界测试暴露）→ 修正后行边界往返测试全过；
4. **deleteRows 残留 indexById 陈旧索引** → 显式清理；
5. **ImeGuard 取消判定语义错误**（组合内 end 必然等于最后 update）→ 改为跨组合比较；
6. **删表撤销丢数据** → RemoveSheet 的 createUndo 抢救完整快照回灌；
7. **resize 手柄只查列右缘**（边界像素归属下一列）→ 左缘同等处理。

以上每一条都有对应测试守护，回归可查。

## 六、已知限制与 v2 建议（诚实清单）

| 限制 | 影响 | v2 方向 |
|------|------|---------|
| 依赖图线性扫描 | 公式数 >1 万后增量查询变慢 | RTree 区间索引（Univer 方案，接口已预留） |
| 冻结行有 API（freezeRows）但滚动布局按「无冻结行」绘制 | 冻结列完整可用；冻结行绘制待补 | 复用 9 视口模型（研究报告 §03/§04 已给出参数） |
| 编辑提交后不自动移动焦点（Excel 的 Enter 下移） | 编辑态导航的 UX 打磨 | AfterEdit 后 moveFocus；Tab 方向已传入编辑器 |
| 填充柄是重复平铺，无序列推导 | 缺日期/等差/中文序列 | 参考 FS dropCell 算法集（研究报告 §07 已列出） |
| 下拉/弹层编辑器会被 root overflow 裁切 | 弹层越出表格边界被剪 | 弹出层挂载 API + Floating UI（研究报告 §07；UI 对接文档已标注） |
| 条件格式/多选区范围样式/行组树 | — | M2/M3 范围 |
| 脏矩形可视化验证 | 需浏览器 | playground `debug: true`（指南已写验收方法） |
