# 状态与路线

本页如实记录 SheetX 当前实现状态与后续路线，便于开发者评估接入时机。

## 当前状态（截至 2026-11）

- ✅ **工程**：pnpm monorepo，20+ workspace，类型检查 / 单测 / 构建全绿。
- ✅ **内核**：`core` 公共契约 + 插件运行时（目录 / 依赖拓扑 / 生命周期 / 扩展点账本）。
- ✅ **引擎（T1–T11）**：IME 守卫、公式增量依赖、脏矩形 blit、远程搜索编辑器、主题令牌等全部实现。
- ✅ **双模式门面**：`SheetX.createGrid` / `SheetX.createSpreadsheet` 与 CDN 入口。
- ✅ **UI 演示**：24 张高保真设计稿与交互（playground `#home` → `#plugins`）。
- ✅ **XLSX 零依赖读写**：最小 OOXML + ZIP，字符串 / 数字 / 富文本 / 日期序列号 / 公式串（含共享公式读取）/ 基础样式 / 数据验证 / 条件格式 / 合并区域，含 1900 闰日兼容。
- ✅ **质量工程**：独立性能基准应用、浏览器级交互 E2E、并行计算骨架、后台渲染加速。
- ⏳ **系统级输入法真机验收**：微软拼音 / 搜狗等需人工验收；E2E 已用真实浏览器 CompositionEvent 序列覆盖守卫语义。

## 授权模型

| 版本 | 授权 | 范围 |
|---|---|---|
| Community | MIT | Grid 基础引擎、基础 Spreadsheet、Canvas 渲染、虚拟滚动、基础编辑器、剪贴板、撤销重做、基础公式、基础校验、CSV 导入导出 |
| Professional | 商业 | 高级公式、高级 Excel 兼容、透视表、高级条件格式、高级打印导出、高级编辑器、数据分析、专业插件 |
| Enterprise | 商业 | 企业级扩展、权限审计、协同编辑、定制主题、OEM、技术支持 |

> 原则：**基础性能不做付费**。虚拟滚动、基本编辑、复制粘贴在社区版就应足够优秀。
